KSLBestDungeon Changelog Archive
================================

Shipped versions before the current one. The packager reads changelog.txt
verbatim (see manual-changelog in .pkgmeta), so that file holds only the
version being built -- otherwise every CurseForge release reposts the whole
history as its release notes. Older sections move here instead of being
deleted: many carry root-cause writeups worth grepping before assuming a bug
is fresh. This file is in the .pkgmeta ignore list, so it never ships.

V1.4 - 2026-09-25

Added:

- A toolbar along the top of the Best Dungeons tab. Sort, All specs, Weight by
  tier and Min items used to sit in an unlabelled dropdown that was easy to miss
  entirely; they are now visible controls, and hovering any of them explains
  what it does.

- A line at the top of the tab saying whose favorites are being ranked (the
  character selected in KeystoneLoot, in class colour) and whether that is all
  specs or one spec only.

- Share button. Posts the ranking to party, instance, guild, say, yell, a
  character by name, or a Battle.net friend. Channels you cannot use right now
  are greyed out with the reason instead of failing with a game error, and the
  confirmation says "Sent to Party" rather than "Sent to PARTY".

- A score key along the bottom of the list: what each tier is worth (Best in
  Slot 100, Catalyst 100, Must have 50, Nice to have 10, Transmog 1). Hovering a
  dungeon now shows how its score was worked out, tier by tier.

- Tiers are shown with KeystoneLoot's own tier icons everywhere: in the corner
  of each item, in each dungeon's summary, in the score key and in tooltips. The
  summary used to be coloured text in a colour scheme of its own.

- The ranking follows KeystoneLoot's Slot menu. Pick Trinket there and Best
  Dungeons ranks dungeons by your trinket favorites only; Favorites or All slots
  ranks every slot. Multi-slot selections and weapon types work the same as on
  KeystoneLoot's Dungeons tab. The top line shows the slot when one is picked.
  It used to be ignored: changing it did nothing here.

- When the list is empty it now says why, with a button to fix it. Every case
  used to say "No favorites found", even when favorites existed and a setting
  was hiding them:
  - Min items hiding every dungeon: says how many dungeons have favorites, with
    a Show all dungeons button.
  - "All specs" off and this spec has none, though other specs do: a Show all
    specs button.
  - KeystoneLoot's Slot menu excluding every favorite: which slot is picked,
    and how to rank every slot again.
  - Nothing favorited yet: how to add favorites in KeystoneLoot, with a Go to
    Dungeons button.

- Defaults button, which puts the ranking options back without reloading your
  interface. /kslbd reset still wipes everything and reloads.

- A welcome note on first install, and a short note about what changed after
  each update. /kslbd notes shows it again. If several of Squizz's addons update
  at the same time, their notes queue up and appear one after another instead of
  drawing on top of each other.

- /rl as a shortcut for reloading your interface, the same as /reload. It is
  only claimed if no other addon already provides it, so an existing one keeps
  its own version.

Changed:

- With "All specs" on, an item favorited on several specs now counts once, at
  the best tier any spec gave it. It used to count once per spec -- a trinket
  marked Best in Slot on three specs added 300 to its dungeon instead of 100 --
  and its icon appeared once per spec as well. Rankings may shift for characters
  with favorites shared across specs.

- Catalyst favorites now count as much as Best in Slot (100, up from 5).
  KeystoneLoot only allows Catalyst on the five tier-set slots, so a Catalyst
  favorite is a drop you mean to turn into a set piece, and it ranked below even
  Nice to have. Dungeons with Catalyst favorites will move up the list.

- Declares support for patch 12.1.5 alongside 12.1.0, so it loads on the
  12.1.5 client without being marked out of date.

- The old settings dropdown no longer sits on top of the first dungeon's item
  icons.

Removed:

- The "Only Show Dungeons with Favorites" option. It never did anything:
  dungeons without favorites were never listed either way.
- "Refresh Now". The list already updates by itself.

Fixed:

- The KeystoneLoot window got 60px shorter every time the Best Dungeons tab
  was selected, including each /kslbd while it was already open. The tab now
  keeps the same size as KeystoneLoot's Dungeons tab, so switching between them
  no longer changes the window, and KeystoneLoot's wide mode carries over.

- The list's scrollbar was drawn outside the window, off its right edge. It now
  sits inside the list.

- KeystoneLoot's footer text was drawn over the bottom of the list.

- Dungeons with more than about eight favorites had their last icons, and the
  "+N more" label, cut off by the edge of the window. Icons now wrap onto a
  second line so every favorite is shown.

- Item icons had no border at all. They were meant to have a border coloured by
  tier, but it did not draw on the current game version, and it replaced
  KeystoneLoot's own quality border. Items have their quality border back.

- The tier icon in the corner of an item showed the tier for whichever spec was
  selected in KeystoneLoot, not the tier it was favorited at, so it could
  disagree with the score when "All specs" is on. It now always shows the
  favorited tier.

- Viewing an alt with "All specs" off ranked it for your logged-in character's
  spec: select a Paladin alt from a Hunter and it said "Beast Mastery only" and
  found nothing. It now follows KeystoneLoot, which switches to all specs when
  you pick another character, and uses a spec picked in KeystoneLoot's class
  menu only when that menu is on the selected character's class.

- The Best Dungeons tab did not appear on your first ever session with
  KeystoneLoot, only after a /reload.

- KeystoneLoot is now a required dependency, so the AddOns list says so when it
  is missing instead of this addon loading and doing nothing.

- Opening the tab built the list three times over. It builds it once.

- Long dungeon names ran underneath the item icons. They are now shortened with
  "..." and shown in full when you hover the row.

- Whispering the ranking to a character by name. The name box was built for an
  older version of the game's popup and would have errored; it was also not
  reachable from any menu.
- A long ranking could be rejected by chat for being over 255 characters. It is
  now cut short at the last dungeon that fits.

1.3 - 2026-08-19

### Fixed

- **Lua error on any Catalyst favorite** ("attempt to perform arithmetic on field '?'"
  at `KSLBestDungeon.lua:155`), which left the Best Dungeons list empty. KeystoneLoot
  added a fifth tier, `TIER_CATALYST = 5`, and the per-dungeon tier counter table was
  only seeded for tiers 1-4, so the first Catalyst item incremented a `nil`. Catalyst is
  now a known tier throughout - counted, scored (weight 5, between Nice and Transmog,
  matching KeystoneLoot's own tier order), and shown as a purple `N Cata` in the tier
  summary. The counter and the scoring loop also tolerate unknown tiers now, so the next
  tier KeystoneLoot adds degrades instead of erroring.

- **The list did not follow spec changes** - switching spec in KeystoneLoot or in-game
  kept showing the previous spec's ranking until a `/reload`. The poll hash was built
  only from the favorites data, which a spec change never touches. It now includes the
  selected character and the active class/spec filter (`Addon:GetFilterStateKey()`).

- **The poll ticker never restarted after the tab was hidden.** `OnShow`/`OnHide` were
  defined on the rankings mixin but never wired as scripts, because the mixin is copied
  onto a plain `CreateFrame()` frame instead of applied from an XML template. They are
  registered explicitly now, and `OnShow` restarts the ticker and refreshes.

1.2 - 2026-08-13

### Fixed

- **Item levels in the Best Dungeons tab were wrong.** Items showed their base item
  level and base quality colour (e.g. Fireproof Drape as an uncommon ilvl 53 instead of
  an epic ilvl 318) no matter what was picked in KeystoneLoot's item level dropdown.

  Root cause: the addon looked up KeystoneLoot's `Upgrade` module through
  `_G.KeystoneLoot`, but that global does not exist — KeystoneLoot keeps its modules on
  an addon-private table and only publishes `_G.KeystoneLootAPI`. The lookup was
  silently `nil`, so every item link fell through to a bare `item:<id>`.

  Item icons are now built from KeystoneLoot's own global button template
  (`KeystoneLootLootIconButtonTemplate`), whose handlers run inside KeystoneLoot and
  therefore always scale to the selected item level.

- **"No favorites found" stayed on screen after adding favorites**, overlapping the
  dungeon list until a `/reload`. The refresh only released the container's child
  frames; the status messages are FontStrings, which are regions rather than children,
  so they were never cleaned up and stacked with every refresh. A single reusable
  message FontString is now hidden at the start of each refresh.

- **Live updates relied entirely on the 1-second poll.** The KeystoneLoot database
  observers registered at startup never attached — same `_G.KeystoneLoot` cause as
  above. The addon now subscribes to `KeystoneLootAPI`'s `FAVORITES_CHANGED` event. The
  poll is kept as a fallback, since that event does not fire when the character or spec
  filter changes in KeystoneLoot.

- **The item level line was missing from tooltips.** Both the row tooltip and the icon
  tooltips were supposed to show the selected upgrade track; that code sat behind the
  same dead `_G.KeystoneLoot` check and never ran.

- **`/kslbd debugui` printed nothing about KeystoneLoot's state** for the same reason.
  It now reports whether the KeystoneLoot API is present, plus the selected tab and the
  current dungeon track and rank.

### Changed

- Item icons gain KeystoneLoot's own behaviour, since they are now its buttons:
  right-click sets the favorite tier, shift-click links the item at the correct item
  level, and the voidcore indicator appears where relevant.
- Icons are 34px with 2px spacing (the KeystoneLoot template's native size), previously
  32px with 4px spacing. The tier-coloured border is kept, because KeystoneLoot's own
  tier corner icon only appears for the spec currently filtered there, which would leave
  cross-spec items unmarked when "Show All Specs" is on.
- The row tooltip lists plain item names instead of item links. A link built here would
  show the wrong item level, and hovering an individual icon now gives the full,
  correct tooltip.

### Removed

- Unused `KSLBestDungeonTabButtonTemplate` and `KSLBestDungeonRankingsFrameTemplate`
  from `ui/main_frame.xml`. Nothing referenced them — the rankings frame is built in
  code.

### Documentation

- Added `CLAUDE.md` covering the addon's architecture, the KeystoneLoot tab injection,
  and specifically which parts of KeystoneLoot are reachable from another addon and
  which are not.
